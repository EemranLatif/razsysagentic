You have already installed crew ai using the installation document 
	uv tool install crewai-cli
	uv tool upgrade crewai-cli
        FYI, Crew ai requires  C++ Build Tools

to check crew is installed 
	crewai --version

to run crewai code you have go to the directory then
	example cd 5_crew cd test
	crewai run
How to create crew project called test
	1. crewai create crew test, it will ask for company, model and api key
	2. cd test
	3. uv sync
